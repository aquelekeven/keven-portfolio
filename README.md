# Keven Alves — Portfólio Criativo

Portfólio pessoal de uma página com abertura animada, destaques, apresentação,
serviços, projetos e contato.

## Como editar

- **Destaques, serviços e projetos:** edite `portfolio-data.js`.
- **Textos e contatos:** edite `index.html`.
- **Visual e animações:** edite `styles.css`.
- **Ilustração:** substitua o conteúdo de `.hero-art` por uma imagem transparente.

Qualquer alteração enviada para a branch `main` dispara a publicação automática
no GitHub Pages.
